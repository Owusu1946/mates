# Mates Product Improvement Proposal

## Overview

Mates should become more than a general-purpose chatbot. Its strongest opportunity is to become a trusted personal AI team that remembers what matters, takes action across connected apps, and asks for permission before performing important or sensitive actions.

Rather than competing with products such as Muse and Grok feature-for-feature, Mates should focus on:

- Personal and controllable memory
- Reliable task execution
- Specialized AI mates
- Proactive assistance
- Trust, transparency and user control
- Strong support for everyday life in Ghana and Africa

## Product principle

> Mates should remember what matters, take care of what is tedious, and ask before anything important happens.

## Key product opportunities

### 1. Useful and controllable memory

Mates should remember important context across conversations while giving users complete control over what is stored.

Potential capabilities:

- “Remember this”
- “Forget that”
- “What do you know about me?”
- View and edit saved memories
- Delete individual memories
- Clear distinction between temporary conversation context and long-term memory
- Per-mate memory permissions
- Explain why a memory was used

Memory should be useful without feeling invasive or unpredictable.

### 2. Convert conversations into actions

Users should be able to turn an intention into an executable plan.

For example:

> “I need to visit Oyibi Police Station.”

Mates could:

1. Create a task
2. Find directions from the user's selected location
3. Compare ride-hailing and public transport options
4. Estimate the cost
5. Set a reminder
6. Follow up if the task remains incomplete

Tasks should have clear states:

- Planned
- Waiting for approval
- In progress
- Blocked
- Completed

### 3. Approval-based action system

Mates should be able to work across connected apps while protecting users from unintended actions.

Before an external or sensitive action, the user should see:

- What will happen
- Which app or account will be used
- Who will receive the message or invitation
- Any cost involved
- What information will be shared
- An approval button
- An option to undo where possible

Examples of actions that should normally require approval:

- Sending an email
- Sending a message
- Creating or cancelling an event
- Making a purchase
- Sharing a file
- Changing or deleting records

The user should also have access to an activity history showing what Mates did.

### 4. Specialized mates that can collaborate

Users should be able to create specialized mates for different areas of their lives.

Examples:

- Everyday assistant
- Finance mate
- Study mate
- Health and routine mate
- Project manager
- Travel mate
- Business mate
- Coding mate

Specialized mates should be able to collaborate when the user requests it.

For example:

> “Ask my project mate and finance mate whether this plan fits our budget.”

The user should be able to see:

- Which mate contributed
- What information each mate accessed
- Which memories were used
- What action is being recommended

### 5. Proactive but controlled assistance

Mates should be able to monitor user-approved events and provide useful reminders.

Examples:

- Unfinished tasks
- Upcoming deadlines
- Calendar events
- Important unanswered emails
- Price changes
- Travel plans
- Repeated routines

Proactive features should include:

- User-controlled watches
- Quiet hours
- Notification frequency controls
- Per-mate permissions
- Clear explanation of why a notification was created
- Easy pause and cancellation

Mates should be helpful without becoming noisy or intrusive.

### 6. Local relevance for Ghana and Africa

Mates can differentiate itself by understanding local needs and workflows.

Potential areas include:

- Ghana cedi support
- Ghanaian businesses and services
- Trotro and taxi guidance
- Ride-hailing comparisons
- MTN MoMo, Telecel Cash and AirtelTigo workflows
- Low-bandwidth mode
- Offline drafts and delayed actions
- Voice notes
- Support for local accents
- Local events, schools, churches and community activities
- Future support for Ghanaian and other African languages

The goal is not only to provide globally correct answers, but to provide locally useful assistance.

## Recommended roadmap

### Phase 1: Core reliability

- Improve memory controls
- Add task extraction from conversations
- Add task states
- Improve Notion, Calendar, Gmail and Maps workflows
- Add approval cards
- Add activity history
- Improve location-based assistance

### Phase 2: Proactive assistance

- Add reminders and follow-ups
- Add watches for emails, deadlines and prices
- Add daily or weekly briefings
- Detect commitments from conversations
- Show blocked and waiting states clearly

### Phase 3: Mates ecosystem

- Allow users to create custom mates
- Add shared workspaces
- Support group conversations with multiple mates
- Add mate-to-mate collaboration
- Add shared memory with permissions
- Introduce reusable workflows and templates

### Phase 4: Advanced capabilities

- Live web research with citations
- Improved voice conversations
- Image understanding
- Document and presentation generation
- Browser-based task completion
- Parallel research and execution agents
- Developer integrations and SDKs

## Highest-priority features

The following three features should be prioritised first:

### 1. Turn this into a plan

Convert a conversation into:

- Tasks
- Owners
- Deadlines
- Reminders
- Dependencies
- Progress states

### 2. Ask my mates

Allow multiple specialized mates to collaborate while showing the user:

- Each mate's role
- Their recommendation
- The context they used
- Any disagreement between them

### 3. Do it for me

Allow Mates to complete actions across connected apps, while pausing for approval before sensitive actions.

## Trust and safety requirements

Mates should:

- Never send or share information without user approval when approval is required
- Clearly distinguish suggestions from completed actions
- Show failures honestly
- Never claim an action succeeded when it did not
- Provide undo options where technically possible
- Allow users to inspect and delete memories
- Keep app permissions understandable
- Make background monitoring visible and controllable
- Respect quiet hours and notification settings

## Suggested success metrics

The product team can evaluate this direction using metrics such as:

- Percentage of conversations that lead to completed actions
- Task completion rate
- Successful action rate
- Approval-to-completion rate
- Number of useful memories created and reused
- Reminder completion rate
- User-reported trust
- User-reported usefulness of proactive suggestions
- Number of connected-app workflows completed successfully
- Rate of users returning to the same mate or workspace

Metrics should be used to improve usefulness and reliability, not to encourage unwanted automation.

## Conclusion

Mates should not try to win by becoming another generic chatbot. Its advantage should be the combination of:

- Personal memory
- Specialized AI mates
- Cross-app execution
- Proactive support
- Strong user control
- Local understanding

The long-term vision is a trusted AI team that helps users manage everyday life, personal goals, work and collaboration.
